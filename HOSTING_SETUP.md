# Как разместить игру на GitHub Pages с сохранением в облаке

Всего два шага: **(A)** завести бесплатную базу данных на Supabase, **(B)** выложить файл игры на GitHub Pages. Всё делается через сайты, без установки программ.

---

## A. Настройка Supabase (5–10 минут, один раз)

1. Зайдите на **[supabase.com](https://supabase.com)** → «Start your project» → войдите через GitHub.
2. Нажмите **New Project**, придумайте имя (например, `savings-game`) и пароль для базы (просто сохраните его куда-нибудь, руками он не понадобится). Регион — любой ближайший (например, Frankfurt).
3. Подождите 1–2 минуты, пока проект создаётся.
4. Слева откройте **SQL Editor → New query**, откройте прикреплённый файл **`supabase-setup.sql`**, скопируйте его целиком и вставьте в редактор. Нажмите **Run**. Должно появиться «Success. No rows returned» — это нормально, скрипт просто создал таблицу и две функции.
5. Слева откройте **Project Settings → Data API** (или **Settings → API** — раздел может называться чуть по-разному в зависимости от версии интерфейса). Скопируйте оттуда два значения:
   - **Project URL** — выглядит как `https://xxxxxxxx.supabase.co`
   - **anon public key** (или **publishable key**) — длинная строка

Готово, база данных настроена и ждёт данные.

---

## B. Вписываем ключи в файл игры

1. Откройте `savings-game-mvp.html` в любом текстовом редакторе (подойдёт даже Блокнот, но удобнее — VS Code или аналог).
2. Найдите (Ctrl+F) строку:
   ```js
   const CLOUD_CONFIG = {
     supabaseUrl: "https://YOUR-PROJECT.supabase.co",
     supabaseAnonKey: "YOUR-ANON-PUBLIC-KEY"
   };
   ```
3. Замените оба значения на те, что скопировали из Supabase, и сохраните файл. Пример:
   ```js
   const CLOUD_CONFIG = {
     supabaseUrl: "https://abcduefgh.supabase.co",
     supabaseAnonKey: "eyJhbGciOi...очень длинная строка..."
   };
   ```
   Больше ничего трогать не нужно — как только в этих полях не останется слов «YOUR-…», игра сама включит облачный вход.

---

## C. Публикация на GitHub Pages (5 минут)

1. На [github.com](https://github.com) нажмите **New repository**. Дайте имя, например `savings-game`, сделайте его **Public**, создайте.
2. На странице репозитория нажмите **Add file → Upload files**, перетащите туда изменённый `savings-game-mvp.html` (лучше переименовать его в `index.html`, тогда ссылка будет короче). Нажмите **Commit changes**.
3. Зайдите в **Settings → Pages** этого репозитория. В разделе «Build and deployment» → «Source» выберите **Deploy from a branch**, ветку **main**, папку **/ (root)**, нажмите **Save**.
4. Подождите минуту-две — вверху появится ссылка вида:
   ```
   https://ваш-ник.github.io/savings-game/
   ```
   Это и есть ссылка, которую можно отправлять в Telegram/Viber.

## Как это работает для ребёнка

1. Открывает вашу ссылку.
2. Первый раз — экран входа: вводит **имя** и придумывает **PIN из 6 цифр**, нажимает «Войти / создать профиль».
3. Браузер запоминает вход — при следующих открытиях этой же ссылки в этом же браузере экран входа больше не появится, игра сразу подхватит свежие данные с сервера.
4. Если ребёнок откроет ссылку на другом устройстве — просто вводит то же имя и тот же PIN, и увидит тот же прогресс.
5. Каждое изменение суммы, полученная награда, открытый сундук — сразу уходит в базу данных, ничего специально нажимать не нужно.

**Кнопка 🚪 в шапке игры** — «сменить профиль» (выход), пригодится, если несколько детей играют по очереди с одного устройства/браузера.

## Важные ограничения (чтобы не удивляться)

- Бесплатный проект Supabase «засыпает», если им не пользоваться **7 дней подряд** — первое открытие после паузы может занять на пару секунд дольше обычного, дальше всё как обычно.
- PIN нужен только для входа в конкретный никнейм — если ребёнок забудет PIN, самый простой вариант «сброса» — зайти в Supabase (Table Editor → players) и удалить его строку, тогда это имя снова свободно для регистрации с новым PIN.
- Пока вы не впишете свои `supabaseUrl`/`supabaseAnonKey` (шаг B), файл продолжает работать как раньше — сохраняет прогресс только в этом браузере, без входа. Это специально, чтобы файл не сломался, если облако ещё не настроено.
